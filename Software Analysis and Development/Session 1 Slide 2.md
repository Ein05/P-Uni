Các kỹ năng phân tích yêu cầu:
* Phân tích chức năng: Giúp hiểu các tiến trình xử lý, dữ liệu vào ra
  * Dùng sơ đồ luồng dữ liệu (DFD)
  * Biểu đồ phân cấp chức năng (FHD)
* Phân tích OOP: Mô hình hóa thực thể theo hành vi đối tượng
  * Dùng UML: Use Case Diagram, Class Diagram, Sequence Diagram
* Quy trình phân tích nghiệp vụ:
  * Mô tả các bước theo góc nhìn người dùng, ví dụ: "Giảng viên đăng nhập -> Chọn môn học -> Nhập điểm -> Lưu -> Xác nhận"
* Phân tích kịch bản:
  * AS-IS: Mô tả quy trình hiện tại
  * TO-BE: Mô tả quy trình cải tiến khi áp dụng hệ thống mới
  * Xử dụng BPMN hoặc flowchart

Các kỹ thuật tập hợp yêu cầu:
* Phỏng vấn
* Khảo sát
* Quan sát
* Nghiên cứu tài liệu
* Họp nhóm
* Prototyping: Xây dựng mẫu thử giao diện/chức năng
